# LabGit-Settings

Учебный проект для изучения возможностей системы контроля версий Git и платформы GitHub. Проект демонстрирует навыки настройки фильтрации файлов, управления атрибутами репозитория и организации правильной структуры каталогов.

## Назначение проекта
Проект создан в образовательных целях для практического освоения:
* Инициализации и структурирования репозитория.
* Игнорирования нежелательных файлов с помощью `.gitignore`.
* Настройки обработки окончаний строк и типов данных через `.gitattributes`.
* Документирования проекта в формате Markdown.

---

## Структура каталогов
В репозитории организована следующая структура хранения файлов:

* **`src/`** — исходный код приложения (консольная программа на C#).
* **`docs/`** — основная документация и описание проекта.
* **`tests/`** — тестовые материалы и файлы для проверки работоспособности.
* **`assets/`** — вспомогательные материалы (изображения, медиафайлы).

---

## Исключаемые файлы (`.gitignore`)
Для предотвращения засорения репозитория настроен фильтр `.gitignore`. Из отслеживания автоматически исключаются следующие категории файлов:

* **Артефакты сборки:** каталоги `build/`, `bin/`, `obj/`.
* **Временные данные:** папка `temp/`, файлы с расширениями `*.tmp`, `*.temp`.
* **Журналы логирования:** папка `logs/`, файлы `*.log`.
* **Локальные настройки и секреты:** файл конфигурации окружения `.env`, приватные настройки `appsettings.Local.json`.
* **Системные файлы:** служебные файлы операционных систем (`Thumbs.db`, `.DS_Store`).
* **Файлы сред разработки:** кэш и настройки IDE Visual Studio и VS Code (`.vs/`, `.vscode/`, `*.user`, `*.suo`).
* **Результаты тестов:** отчеты и логи тестирования из папки `TestResults/`.

## Настройки репозитория (`.gitattributes`)
В проекте заданы правила обработки файлов для обеспечения кроссплатформенной совместимости:

* **`text=auto`** — автоматическое определение Git'ом текстовых файлов для нормализации окончаний строк.
* **`*.cs text eol=crlf`** — файлы исходного кода C# принудительно используют окончания строк Windows (`CRLF`).
* **`*.md`, `*.txt` text eol=lf** — файлы документации используют стандартные окончания строк Unix/Linux (`LF`).
* **`*.png`, `*.jpg`, `*.pdf`, `*.zip` binary** — указанные типы файлов обрабатываются как бинарные (двоичные) данные без попыток слияния или изменения строк.
